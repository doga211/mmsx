# Maxicare Medical & Surgical Complex — Complete HTML Prototype

Static multi-page hospital website prototype using the supplied Maxicare logo.

## Pages
Home, About, Services, Departments, Doctors, Facilities, Patient Information, Appointment, Contact.

## Run
Open `index.html` directly, or serve the folder with:
python -m http.server 8080

Then visit http://localhost:8080
